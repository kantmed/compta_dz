# Comptabilité Algérienne

Projet de comptabilité pour l'Algérie basé sur Odoo 20 Community.

- Plateforme : Odoo 20 Community
- Python : 3.12
- Addons personnalisés : /home/odoo20/addons/comptabilite
- Langues prévues : français, arabe, anglais
- Devise de tenue : DZD, avec prise en charge des opérations multidevises

Principes :
- Réutilisation des modules natifs Odoo.
- Séparation des fonctionnalités en modules spécialisés.
- Développement modulaire, sécurisé et multi-société.

Les modules sont en préparation. Ce dépôt suit l'évolution du projet.
