# ca_referential

Module de référentiels communs pour Comptabilité Algérienne.

## Fonctionnalités

- Formes juridiques.
- Catégories d'activité économique.
- Données de référence multilingues.

## Dépendances

- `base`
- `ca_core`
- `ca_audit_log`

## Installation

Installer `ca_core` et `ca_audit_log`, puis installer `ca_referential`.

## Tests

Les tests automatisés couvrent la création, l'unicité, la hiérarchie et l'état actif/inactif.
