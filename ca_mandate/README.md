# ca_mandate

Module de gestion des mandats comptables.

## Fonctionnalités

- Mandats entre cabinets et sociétés clientes.
- Missions configurables.
- Dossiers couverts.
- Collaborateurs autorisés.
- Cycle de vie et historique.

## Dépendances

- `base`
- `ca_core`
- `ca_accounting_folder`
- `ca_company_profile`
- `ca_audit_log`
