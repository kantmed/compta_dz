# ca_collaboration

Module de collaboration entre cabinets, sociétés clientes et collaborateurs.

## Fonctionnalités

- Collaborations.
- Tâches.
- Demandes de documents.
- Messages.
- Tableau de bord simplifié.

## Dépendances

- `base`
- `ca_core`
- `ca_accounting_folder`
- `ca_company_profile`
- `ca_audit_log`
- `ca_mandate`

## Sécurité

Les accès sont contrôlés par société, collaboration, mandat et affectation.

## Traductions

Français et arabe sont fournis. L'anglais est la langue source.
